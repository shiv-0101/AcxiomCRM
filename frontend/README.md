# AxiomCRM frontend

The AxiomCRM React workspace provides the authenticated dashboard, CRM record views, search, follow-up scheduling, and API-backed create flows.

Run from this directory:

```powershell
npm install
npm run dev
```

Set `VITE_API_BASE_URL` in `.env` when the backend is not running at `http://localhost:5000/api`. Use `npm run build` to create the production bundle.
